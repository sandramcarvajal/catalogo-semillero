# catalogo-semillero

Aplicación web de catálogo de productos desarrollada con Angular 17. Muestra productos obtenidos desde la API pública Platzi Fake Store (EscuelaJS) y permite navegar por ellos desde el navegador.

## Requisitos

Antes de ejecutar el proyecto se requiere tener instalado:

* Node.js 20 LTS o superior
* npm
* Angular CLI 17

Para verificar las versiones:

```bash
node --version
npm --version
ng version
```

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/sandramcarvajal/catalogo-semillero.git
```

Ingresar al proyecto:

```bash
cd catalogo-semillero
```

Instalar las dependencias:

```bash
npm install
```

## Cómo levantar el proyecto

Iniciar el servidor de desarrollo:

```bash
ng serve
```

Abrir en el navegador:

```
http://localhost:4200
```

La aplicación se recarga automáticamente cada vez que se guarda un cambio en el código.

## Compilar el proyecto

Para generar la versión de producción:

```bash
ng build
```

Los archivos compilados quedan en la carpeta `dist/`.
